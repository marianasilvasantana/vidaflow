Início Sobre

Sobre o Vida Flow

O Vida Flow é um projeto desenvolvido para auxiliar na organização e no gerenciamento de informações relacionadas a procedimentos cirúrgicos.

Nosso objetivo

O objetivo do Vida Flow é facilitar o gerenciamento de pacientes, hospitais, médicos, cirurgias, recursos, solicitações e agendamentos, centralizando essas informações em um único sistema.

Como funciona

O sistema organiza informações de hospitais, pacientes, médicos, recursos hospitalares e salas cirúrgicas. A partir desses dados, é possível registrar solicitações de cirurgia e realizar agendamentos.

Principais recursos

  • Gerenciamento de hospitais
  • Cadastro e consulta de pacientes
  • Gerenciamento de médicos
  • Cadastro de cirurgias
  • Controle de recursos hospitalares
  • Gerenciamento de salas cirúrgicas
  • Solicitação de cirurgias
  • Agendamento de procedimentos
  • Dashboard para acompanhamento de informações
  • Chatbot para auxiliar os usuários

Tecnologias

  • HTML e CSS — interface
  • Python / FastAPI — backend e API
  • PostgreSQL — banco de dados
